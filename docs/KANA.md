# 히라가나 · 가타카나 표

하루어휘 앱의 **일본어 → 오늘의 통합 글 → 「가나표 보기」** (전체 듣기 버튼 옆)에서 같은 표를 펼쳐 볼 수 있어요. 앱에서는 칸을 누르면 소리가 나요.

## 알아두면 좋은 것

- **작은 っ (ッ)**: 다음 자음을 한 번 더 — きって kitte (킷테), ベッド beddo (벳도)
- **ー (장음)**: 앞 소리를 길게 — コーヒー kōhī (코-히-). 주로 가타카나(외래어)에서 써요.
- **は・へ・を 가 조사일 때**: は → wa (와), へ → e (에), を → o (오) — 예: わたしは (와타시와)
- **ぢ・づ**: 소리는 じ・ず 와 같고 드물게 써요.
- **헷갈리기 쉬운 짝**: シ(shi)/ツ(tsu), ソ(so)/ン(n), ぬ(nu)/め(me), る(ru)/ろ(ro), わ(wa)/れ(re)/ね(ne)
